## 1. 已确认结论

1. 编辑器与展示页原“AI 智能客服”由“AI 智能设计助手”完全替代，不保留面向用户的知识库问答入口。
2. AI 入口仅在编辑器显示；预览页和展示页不显示。
3. 默认使用 DeepSeek：文本模型 `deepseek-v4-flash`，视觉模型 `deepseek-v4-flash-vision-exp`，BaseURL `https://api.deepseek.com`；三者均可由管理员修改。
4. 首期开放“选中组件”和“当前页面”；整张大屏只有在 M9.2 完成最多 200 组件性能验证后才开放。
5. 参考图支持 PNG、JPEG、WebP，单张不超过 10MB。
6. AI 只生成受控声明式配置，不生成或执行 Vue、JavaScript、CSS、HTML、SVG 原文、ECharts 函数或第三方插件。
7. 参数化边框进入首期；高还原九宫格图片边框按已确认的 M9.6 单独开发。
8. 管理员提升公共组件保留接口和权限，首期不开放 UI。
9. 首期提供服务端用户级限流和调用统计，不建设费用额度系统。
10. 个人预设更新时递增当前 `specVersion`，不建设可回滚历史版本库；已有大屏依靠实例快照保持不变。
11. 旧 `/ai/chat`、`/ai/kb-docs*` 停止新调用，知识库数据保留，不执行自动删除迁移。
12. 参考图自定义图表以“尽量高还原”为目标：保留 v1 快照兼容，新生成结果使用 SafeChartSpec v2；M9.6 九宫格图片边框由可选项调整为已确认增强。

## 2. 产品目标

- 用户可通过自然语言修改选中组件或当前页面的视觉样式。
- 用户可上传参考图，提取配色、字体层级、背景、图表和边框风格。
- 用户可生成临时安全图表或参数化边框，并继续配置数据与允许的样式。
- 用户可把满意的图表或边框保存为个人组件，在后续大屏中复用。
- 所有 AI 修改先预览、后应用，不自动保存大屏；一次应用对应一次撤销。
- 编辑器、预览页和展示页复用同一安全 renderer，渲染结果一致。
- 个人预设更新或删除后，已使用该预设的大屏仍可编辑、预览和展示。

## 3. 范围

### 3.1 首期范围

- AI 智能设计助手面板。
- 自然语言修改已有组件样式。
- 当前页面批量风格统一及页面背景颜色/透明度修改。
- DeepSeek 参考图风格提取。
- 安全自定义折线图、柱状图、饼图、组合图、漏斗图、雷达图和仪表盘。
- 参数化装饰边框。
- 个人组件保存、重命名、复制、更新、删除和再次添加。
- 文本/视觉模型配置、能力测试、调用限流和统计。

### 3.2 不在首期范围

- AI 修改组件位置、尺寸、层级、锁定、隐藏、分组和删除状态。
- AI 修改数据绑定、API 配置、静态业务数据、事件或下拉框联动。
- 根据截图自动还原整张大屏布局和业务数据。
- AI 发明新的数据协议或字段映射规则。
- AI 生成或执行代码、动态表达式、原始 SVG、CSS、HTML 或 ECharts 回调函数。
- 图片像素级无损复刻、用户组件市场、跨用户共享和协同编辑。
- 操作手册知识库问答和展示页 AI 客服。

## 4. 核心概念

### 4.1 AI 修改方案

模型只返回结构化候选方案。方案包含摘要、目标、允许字段的新值、跳过项、不支持项和警告。后端不直接写大屏或数据库，前端只有在用户点击“应用”后才原子更新 screenStore。

### 4.2 临时组件

AI 生成后加入当前大屏的安全组件实例。它始终携带完整 `definitionSnapshot`；即使未保存为个人组件，只要用户保存大屏，预览页和展示页仍能独立渲染。

### 4.3 个人组件预设

用户保存的可复用定义。预设只提供创建新实例时的当前模板，已有实例不引用预设实时渲染。

### 4.4 组件定义快照

动态组件实例的自包含安全定义，包含固定 `rendererKey`、`specVersion`、数据协议、默认尺寸、styleSchema、双主题默认样式、styleMode 和 safeSpec。`presetId` 只用于追踪，不是运行时依赖。

### 4.5 安全 renderer

- `echarts-safe-v1`：把通过白名单校验的 SafeChartSpec 和协议数据转换为 ECharts option。
- `border-parametric-v1`：使用预先实现的 SVG DOM 图元和 CSS 变量绘制边框。
- `border-nine-slice-v1`：透明 PNG/WebP 九宫格图片边框；`assetId` 指向永久边框资产，切片参数可编辑；遮挡/水印等写入 warnings 并标记 approximate。

服务端不能返回组件路径，前端不能动态加载或执行服务端代码。

`echarts-safe-v1` 同时读取历史 `schemaVersion=1` 和新版 `schemaVersion=2`。v2 仍是产品自有声明式语法，不等同于、也不透传原始 ECharts option。

## 5. DeepSeek 模型接入

### 5.1 配置

- `provider`: 固定为 `deepseek`。
- `baseUrl`: 默认 `https://api.deepseek.com`。
- `textModel`: 默认 `deepseek-v4-flash`，允许管理员改为其他已验证文本模型。
- `visionModel`: 默认 `deepseek-v4-flash-vision-exp`，允许管理员修改。
- `visionEnabled`: 管理员显式开关，不依赖自动猜测模型能力。
- `apiKey`: 加密存储，只写不读，接口只返回掩码。

### 5.2 调用规则

- 后端通过 Axios 调用 OpenAI 兼容 Chat Completions，不新增 SDK。
- 文本与视觉模型分别测试；视觉失败不影响文本能力。
- 文本方案启用 JSON Output，并在提示中包含目标 JSON 示例。
- 空内容自动重试一次；第二次仍为空、JSON 无法解析或契约不合法时返回明确错误。
- 图片以内联 Base64 放在 user message 中并使用 `detail='original'`；不生成公网 URL，不放在 system/assistant message。
- 不启用模型工具调用、联网搜索、代码执行或外部请求能力。

能力基准（核对日期 2026-09-08）：[DeepSeek 模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)、[Vision](https://api-docs.deepseek.com/guides/vision/)、[JSON Output](https://api-docs.deepseek.com/guides/json_mode/)。模型与限制可能变化，因此正式实现以管理员能力测试结果为准，不按模型名称猜测能力。

## 6. 用户交互

### 6.1 面板

面板依次包含：

1. 作用范围：选中组件 / 当前页面 / 整张大屏。
2. 上下文摘要：目标数、锁定数、隐藏数、组件类型。
3. 文本指令。
4. 可选参考图。
5. “生成修改方案”。
6. 摘要、字段差异、跳过项、不支持项和警告。
7. “预览”“应用”“重新生成”“取消”。

不设置“使用帮助”或知识库 Tab。

### 6.2 目标规则

- `selected` 无有效选中组件时禁止提交。
- 锁定组件始终跳过并列出原因。
- 隐藏组件默认跳过；只有用户明确要求时才纳入。
- 组外模式选中组合时按整组选中结果处理；组内模式只处理实际选中的子组件。
- 当前页最多 50 个组件；整屏功能开启后最多 200 个组件，超限要求缩小范围。

### 6.3 预览与应用

- 唯一正式编辑状态仍是 `screenStore.screen`。
- store 维护本地单调递增 `editorRevision`；所有正式画布修改均递增。
- 方案携带生成时的 `editorRevision`。画布发生变化后，方案立即过期并禁止应用。
- 预览使用独立 `previewDraft` 覆盖层，不写 screen、history、dirty 或保存接口。
- 应用前重新校验版本和全部操作；在内存副本成功执行后，通过单个 `applyAiPlan` action 替换正式状态。
- 一次应用只压入一次历史快照并标记未保存；Ctrl+Z 一次完整恢复。
- 关闭面板、取消、重新提交或组件卸载时取消请求并清理 draft。

## 7. 样式生成规则

### 7.1 已有组件

- AI 只能写入目标共享 `styleSchema` 中 `aiWritable=true` 的字段。
- 文本内容默认不可写；如业务后续允许 AI 改标题文案，必须单独进入契约和权限评审。
- 页面只能修改背景 `color` 和 `opacity`；背景图片不由样式方案写入。
- 后端按共享字段目录校验一次，前端应用前用同一校验器复检。

### 7.2 无法精确表达时

按以下顺序处理：

1. 精确映射现有字段。
2. 使用现有颜色、线宽、透明度、圆角、阴影等字段安全近似，并标记“近似还原”。
3. 建议生成临时安全自定义组件。
4. safe renderer 能表达但无法开放字段编辑时，经用户确认生成 `styleMode='locked'` 图表。
5. 依赖函数、renderItem、脚本、未知图元、第三方插件或外部资源时明确不支持。

不支持项必须包含效果描述、原因、处理方式和可选建议，禁止静默丢弃。

## 8. 参考图

- 上传独立于通用资源接口：PNG/JPEG/WebP，≤10MB、单边≤8192px，同时校验扩展名、MIME、文件头和图片尺寸。
- 资源绑定 ownerId，其他用户不可读取、使用或删除。
- 上传前提示图片会发送至管理员配置的 DeepSeek 服务。
- 图片中的文字指令视为不可信内容，不能覆盖系统规则、改变范围或触发其他操作。
- 临时资源包含 `expiresAt`，默认 24 小时后由 TTL 自动清理；关闭面板时尽力主动删除，TTL 作为兜底。
- 日志不得记录 Base64、完整图片、提示全文、API Key 或 Authorization。

风格提取范围：明暗和背景层级、主色/强调色/辅助色/告警色、字体层级、图表线宽/柱宽/圆环比例/图例/标签密度、边框形态和发光、整体留白与信息密度。

## 9. 安全自定义图表

- 雷达图参考图的同心多边形层叠背景使用 `radar.splitNumber` 与按从内到外排列的 `radar.splitAreaColors` 表达；背景分区填充与数据多边形的 `areaOpacity` 独立，不为背景伪造数据系列。按参考图保留层数、逐层颜色和透明度，无层叠背景时不强行添加。
- 雷达图按参考图保持背景与数据主体的明暗关系，不使用固定色表替代观察；标签间距 `axisNameGap` 投影到 `visual.coordinate`，不能落入系列配置。实际还原验证应读取已保存快照，区分数据轮廓差异与样式差异。
- 实色分层参考图须显式表达网格是否显示，并核对内外层明暗顺序；数据填充优先使用不带 alpha 的颜色与单一面积透明度。线框参考图保留线框语义。坐标系的轴线、分隔线和刻度线下的扁平颜色/宽度等描边属性归一化到 `lineStyle`，已有嵌套属性优先，后续仍需通过安全校验。
- 投影层对实色分层 `splitAreaColors` 做确定性明暗方向检查：外圈明显亮于中心时纠正为中心更亮、外圈更淡并降为 `approximate`；中心 alpha 仍过低时提升中心透明度并尽量保留外圈淡化；两色交替与显式关闭 `splitArea` 的线框语义不纠正。
- 分层密度按参考图色带数量决定，不按雷达维度数量决定；明确提供超过两种分区颜色但省略层数时，以校验后的颜色数量补全层数，显式层数保持优先，两色交替背景保留默认行为。可见同心环有多少就保留多少，禁止把 7~8 层压缩成 4~5 层，也不要凭空加层。填充色 alpha 与区域透明度相乘，应避免重复压暗；可编辑折线与组合图的面积填充按当前实例透明度启停。
- 必须选择现有 `ProtocolKind`，生成符合协议的中文模拟数据。
- 历史 `SafeChartSpec schemaVersion=1` 继续可读；新生成图表使用 `schemaVersion=2`。
- v2 在不绑定业务数据的前提下，覆盖图例布局、坐标轴细节、标签、渐变、阴影、强调态、动画、系列图元、饼图中心/半径、雷达图中心/半径和仪表盘结构等高还原字段。
- 模型结果先经过安全投影：正式字段归一化；常见枚举别名、百分比字符串和扁平视觉字段转换为正式值；缺少字段使用确定性默认值但不产生降级提示；其他纯 JSON 视觉/布局字段进入 `visual` 的固定 renderer 目标，不再逐字段扩充白名单。
- 安全归一化、补默认值和当前图表族不适用字段不降低 fidelity；只有视觉信息被截断、替换或丢弃时才返回 `approximate`。
- 函数 formatter、renderItem、HTML、CSS、完整 SVG/XML、外部 URL、data URI、危险对象键及疑似可执行内容必须硬拒绝。纯文本 formatter 只允许固定占位符；`path://` 仅允许受长度、命令数与坐标范围限制的标准路径。
- 投影完成后必须再次通过 shared 严格校验；前端只消费终检通过的 spec，不能自行放宽字段。
- `fidelity='exact'` 表示目标效果完全落在 v2 语法内；发生视觉字段丢弃、替换或安全近似时必须返回 `approximate`。无法安全近似的效果进入 `unsupportedFeatures`，不得让用户逐个字段试错。
- `styleMode='editable'` 时 styleSchema 只能从 renderer 批准字段目录生成。
- `styleMode='locked'` 时不显示样式设置，但静态数据和 API 数据绑定保持可用。
- 用户数据覆盖模拟数据；safeSpec 不能保存并强制使用业务数据。
- 系列数量变化时按固定规则循环复用系列样式；无法兼容时显示协议错误，不继续显示旧数据伪装成功。
- 同一页面按最多 200 个组件评估；不因高还原字段引入逐帧动画、外部纹理或额外 renderer 实例。

## 10. 参数化边框

SafeBorderSpec 至少包含角标类型/尺寸、主色、强调色、背景色、线宽/透明度、内外发光、标题区位置和内容内边距。

renderer 只创建批准的 SVG DOM 图元并绑定 CSS 变量，不接受原始 SVG/path/CSS/HTML。横向、纵向和极端宽高比下四角不得变形，边线连续伸缩。

## 11. 个人组件

### 11.1 保存与加载

- 保存字段：名称、图表/装饰分类、分组、默认主题、可选描述。
- 系统保存完整安全定义、数据协议、默认模拟数据、预览图、ownerId 和时间。
- 登录后加载“我的组件”；内置组件优先按静态注册表解析，动态组件按实例快照解析。
- 从预设添加时生成新实例 ID，并复制当前 definition；不得只保存 presetId 引用。

### 11.2 更新、复制和删除

- 更新允许修改名称、描述和已校验定义，当前 `specVersion + 1`。
- 首期不保留可查询/回滚的历史版本；已有实例因持有旧快照而保持不变。
- 复制创建新预设 ID、`specVersion=1`、ownerId=当前用户。
- 删除前二次确认；只删除组件库入口，不扫描或修改大屏。
- 找不到预设时使用实例快照；快照也无效时显示“组件配置不可用”。
- 个人预设仅本人可操作；管理员提升时复制为公共预设，不改变原个人预设。

## 12. 安全与数据最小化

- 模型响应、参考图和客户端上下文均按不可信输入处理。
- 递归拒绝 `__proto__`、`prototype`、`constructor`。
- 后端验证用户可访问 screenId、pageId 和目标组件，动态快照必须重新通过安全 renderer 校验。
- 仅发送目标组件 ID、模板、名称、主题、锁定/隐藏状态、当前样式和必要快照。
- 禁止发送 API 密钥、鉴权头、API 配置、真实接口响应、无关页面或用户数据。
- 服务端记录用户、能力、模型、结果、耗时和 token 统计；不记录图片和完整 prompt。
- 模型超时、限流、空响应、格式错误和校验失败均显式返回，不改变画布。

## 13. 验收标准

### 13.1 样式方案

- “隐藏图例、线宽改为 4、蓝青配色”只产生合法样式字段。
- AI 返回未声明、只读或越界字段时拒绝该字段并显示原因。
- 预览不修改正式状态；应用后一次撤销完整恢复。
- 画布变化后旧方案无法应用。
- 锁定/隐藏跳过规则、部分合法与全部非法结果均有明确反馈。

### 13.2 DeepSeek 与参考图

- 文本模型与视觉模型可独立测试和启停。
- 视觉模型不可用时图片入口禁用，文本样式编辑仍可用。
- 图片以内联 Base64 经后端发送，非法格式、伪装文件、超限和越权请求拒绝。
- 图片文字不能触发删除、数据修改、外部请求或越权操作。
- DeepSeek 空 JSON 只重试一次，仍失败时不改变画布。

### 13.3 动态组件

- 生成组件声明有效数据协议，默认数据通过 shared 校验。
- 未知 renderer、函数 formatter、renderItem、HTML、CSS、完整 SVG/XML、外部 URL 与数据注入均拒绝；纯文本 formatter 和受限 `path://` 可通过。
- v2 的安全视觉字段统一投影到固定 renderer 目标，枚举别名、百分比与扁平字段归一化不显示近似提示，不再靠逐个补白名单才能生成。
- 饼图、雷达图和仪表盘的中心、半径、标签与主要装饰参数能从特殊参考图映射；超出语法的效果明确列入不支持项。
- 编辑器、预览页和展示页表现一致。
- 锁定样式图表仍可切换静态/API 数据；数据不符合协议时显示明确错误。
- 个人预设更新或删除后，旧实例继续依靠快照渲染。
- 未授权用户不能访问他人的个人预设和参考图。
