# ScreenCraft 开发里程碑（milestones.md）

> 版本：v0.3。本文件是 Cursor 的**开发节奏与验收基准**：严格按 M0→M8 顺序推进，一个里程碑内完成验收清单后才进入下一个；每个里程碑结束必须 git commit（建议每完成一个功能点即 commit）。
> 预估请求数为 Cursor Agent 快速请求的粗估，供额度管理参考（Pro 500 次/月）；实际以功能点拆分为准，超支 50% 以上时停下来与用户复盘。
> 依赖关系：M3 依赖 M1/M2；M4 依赖 M3；M5/M6 依赖 M4；M7 依赖 M5；M8 依赖 M4（变体量产）与 M7（AI 客服悬浮入口在编辑器/展示页均有）。

---

## M0 工程脚手架

**范围**：pnpm workspace 三包（frontend / backend / packages/shared）、TypeScript strict、ESLint + Prettier（可后置到任意里程碑补）、`.env` 加载、MongoDB 连接、种子脚本（初始化 admin/ScreenCraft@2026，首次登录强制改密标记）、Axios 统一封装骨架（get/post、token 注入、`{code,message,data}` 解包、401 跳登录、ElMessage 报错）。

**不做**：任何业务页面。

**验收清单**：
- [ ] `pnpm i && pnpm -r dev` 前后端均可启动；前端访问后端健康检查返回 200
- [ ] shared 包被前后端同时引用（一个类型 + 一个错误码常量即可验证链路）
- [ ] 种子脚本可重复执行（幂等：已存在则跳过）
- [ ] `.env.example` 全部变量在代码中有对应读取，无硬编码密钥
- [ ] Axios 封装单例就位，业务代码无法绕过（约定 + review）

## M1 认证与用户管理

**范围**：登录页（视觉按 `designs/ui/screencraft-ui/login.html` + design.md §8）、`POST /auth/login` / `GET /auth/me`、JWT（7 天）、首次登录强制改密、用户管理页（列表/新建/重置密码/启用禁用，admin 守卫）。对应 PRD §4.5、api.md §3.1。

**验收清单**：
- [ ] admin/ScreenCraft@2026 首次登录强制改密；改密后旧密码失效
- [ ] 错误凭据：toast 报错 + 密码框标红；禁用账号无法登录
- [ ] 普通成员登录后看不到「管理后台」导航与入口；直接敲 /users 接口返回 403
- [ ] token 过期后任意操作跳回登录页

## M2 项目 / 大屏列表 / 模板库

**范围**：项目列表页（卡片/新建/重命名/删除二次确认）、大屏列表页（分类筛选 chips、卡片、复制/删除/投放标记、新建空白）、模板库 Tab（公共/个人、分类筛选）。**本里程碑缩略图用统一占位图**（M8 再接自动截图）。对应 PRD §4.1~4.3、api.md §3.2~3.4。项目删除需提示大屏数量；已投放大屏删除强警示。

**验收清单**：
- [ ] 项目→大屏→新建空白大屏→直接进编辑器（M3 前编辑器可为空白页占位）全链路可走
- [ ] 分类值域严格为：通用/工业/政务/医疗/交通/能源
- [ ] 复制大屏名称后缀「-副本」；删除均二次确认
- [ ] 投放标记切换后列表徽章即时更新

## M3 编辑器骨架

**范围**：编辑器三栏布局（48px 工具栏 / 288px 左面板 / 324px 右面板，design.md §7）、页面层级树（增删改/父子层级/跳转选择源）、画布（1920×1080、点阵网格 + 网格开关、缩放 20%~400%、空格拖拽、适应画布/画面居中）、组件以**占位框**渲染（拖动/八向缩放/比例锁/多选/微调）、选中工具条（图层/显示隐藏/锁定/组合/打散/删除）、快捷键全套（PRD 4.4.4 表）、撤销重做（不可变快照栈）、保存/导出 JSON/清空画布、beforeunload。组件渲染真实化在 M4。

**验收清单**：
- [ ] 新建组件→拖动→缩放→锁定→隐藏→组合→双击进组→Esc 退组 全部可用
- [ ] 撤销/重做覆盖：添加/删除/移动（拖拽结束记一次）/缩放/组合/样式变更
- [ ] Ctrl+C/V 同大屏跨页面粘贴；Ctrl+BackSpace 删除；方向键微调（Shift 10px）
- [ ] 刷新页面未保存弹原生确认；保存后刷新无提示
- [ ] 100 个占位组件/页时拖拽无明显卡顿

## M4 注册表框架 + 黄金样例

**范围**：ComponentTemplate 注册表框架（architecture.md §2.3）、组件库面板（四分类/明暗 Tab/搜索/点击添加到画布中央）、右侧面板三 Tab 骨架（数据绑定/样式设置/交互事件）、styleSchema 声明式表单渲染器、dataProtocol 驱动的 vxe-table 静态数据表格（加行加列/右键菜单六项/协议校验黄色警告）、**唯一真实组件：折线图样式1（chart-line-1，严格按 docs/golden-sample.md 实现）**、底板框通用样式、页面背景设置。对应 PRD §4.4.3/4.4.5、§5。

**验收清单**：
- [ ] 黄金样例与 golden-sample.md 逐字段一致（meta/styleSchema/defaultStyle/默认数据）
- [ ] 样式面板全部字段可改且实时反映到画布与运行时；切主题默认样式随之切换
- [ ] 静态数据改坏协议 → 黄色警告不阻断保存；改好 → 警告消失
- [ ] **本里程碑结束由用户验收黄金样例，通过后才能进入 M8 量产**

## M5 API 配置页 + API 数据绑定

**范围**：API 配置列表页（名称/类型/路径/引用数/删除保护）、SQL 生成表单（CodeMirror 6、:paramName 占位符、参数表）、外部登记表单、试运行（JSON 表格预览 + 协议符合提示）、运行时 `GET/POST /data/:apiId`（SQL 只读校验/参数化绑定/外部代理 + SSRF 白名单）、组件数据绑定 API 类（选择 API/轮询间隔≥5s/参数 defaultValue 首取）。对应 PRD §6、api.md §3.5/3.6。

**验收清单**：
- [ ] SQL 含 UPDATE/DELETE/多语句/注释 → 拒绝并报 4101；参数化绑定防注入
- [ ] 外部 API 鉴权信息不出现在任何前端响应；白名单外域名拒绝（4102）
- [ ] 被引用的 API 删除被拦截并提示引用数量；解除引用后可删
- [ ] 试运行结果与组件协议做符合性校验（4201 提示）

## M6 交互事件 + 下拉框联动

**范围**：事件 Tab UI（事件列表/新增/编辑/删除）、四类动作（跳页面/跳超链接/显示隐藏/调 API）、触发条件（点击/双击/进入/离开）、下拉框组件（选项协议/默认选中项）、change 联动（同名参数注入 + 重新取数）。**在编辑器内可配置，实际执行在 M7 运行时生效**；编辑器内预览联动行为可先用「预览页」验证。对应 PRD §4.4.6。

**验收清单**：
- [ ] 按钮点击 → 目标组件显示/隐藏/切换（编辑器选中态不受影响，运行时生效）
- [ ] 下拉框切换 → 目标组件 API 同名参数注入并重新取数；首取用 defaultValue
- [ ] 事件配置错误兜底：目标组件被删除后事件自动失效不报错

## M7 展示页 / 预览页 / 适配 / 轮询 / 天气

**范围**：运行时渲染器（与编辑器共用组件渲染器）、预览页（全屏无控制条 + 未保存提示二选一弹窗）、展示页 `/display/:id`（右上配置/全屏按钮、鼠标静止 3s 淡出）、四种适配方式（design.md §9）、API 组件轮询（页面切换/卸载清理定时器）、天气组件 ×2 样式（内置腾讯 LBS 代理 /weather?adcode=、显示指标/时间格式/本地时钟）、数据异常占位。对应 PRD §4.4.7~4.4.9、§8、§9。

**验收清单**：
- [ ] 四种适配方式在 16:9 / 超宽 / 竖屏窗口下表现符合 design.md §9
- [ ] 天气：adcode 改变即更新；系统时间为本地实时时钟；轮询默认 300s
- [ ] 断网/接口失败 → 「数据加载失败」占位，恢复轮询后自动重试；无白屏无崩溃
- [ ] 预览页无控制条；展示页控制条三按钮可用（截图按钮若依赖 M8 的 html2canvas 收尾，可先占位隐藏）
- [ ] M6 全部事件在预览/展示页真实可触发

## M8 变体量产 + AI 客服 + 预览图 + 收尾

**范围**：
- **变体量产**：按黄金样例模子批量生成其余 62 个模板（图表 34 + 指标卡 12 + 表格 2 + 天气 1 + 边框 5 + 媒体 2 + 控件 5），**按族进行**（一族一次会话：先折线族剩余 4 个 → 柱状族 → …），每族完成即 commit + 抽查 1 个变体三 Tab 完整性

- **AI 客服**：对话窗（编辑器/展示页右下悬浮）、知识库文档管理（md/txt 上传/编辑/删除/重索引）、自研 RAG（分块→embedding→检索→生成；无 embedding 降级 BM25）、LLM 配置页（BaseURL/Key/Model、Key 密文回显）
- **收尾**：保存缩略图真实截图（视频用占位图）、展示页截图按钮、UI-SPEC §8 验收自查清单全量过一遍

**验收清单**：
- [ ] 63 模板全部可添加、可配置、双主题默认样式正确（抽查每族 ≥2 个）
- [ ] 预览图脚本一键生成；新变体纳入注册表后重跑脚本即可补图
- [ ] AI 客服：知识库问答命中手册内容；无 embedding 配置时降级 BM25 仍可用；Key 不回显
- [ ] 全部文档（PRD §1.5 做/不做）逐条对照，无缺漏

## 通用纪律（每个里程碑适用）

1. 开工前：读 `.cursorrules` + 当前里程碑范围 + 对应 PRD 章节；先出简短实现方案（涉及哪些文件/接口）再动手。
2. 收尾时：对照本文件验收清单自检 + PRD 对应章节自检，回复中给出「改动文件 / 对应章节 / 自检结论」。
3. 每个功能点完成即 commit；里程碑完成打 tag（m1、m2…）。
4. 遇到文档未覆盖的细节：**停下来问**，确认后回写文档，禁止猜。
