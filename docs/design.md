# 大屏配置系统 设计规范（design.md）

> 版本：v0.4（AI 智能样式编辑设计版）。色值为初始值，整体视觉以「深色科技风」为默认、同时支持浅色主题；最终色值待用户审核微调。
> v0.4 变更：新增 AI 智能设计助手、方案差异与预览状态、“我的组件”、锁定样式组件和 DeepSeek 管理配置；预览页/展示页移除 AI 入口。
> v0.3 历史变更：边框套系最终收敛为默认深蓝/工业蓝/科幻紫三套；编辑器布局尺寸按高保真原型回写为 48px 工具栏、288/324px 面板。
> 实现方式：SCSS + CSS 变量（主题）+ ECharts 主题包。组件默认样式随明/暗主题各一套。

---

## 1. 主题机制

- 两套主题：`dark`（默认）/ `light`，通过根节点 `data-theme="dark|light"` 切换 CSS 变量。
- ECharts 注册两个主题包（`ds-dark` / `ds-light`），图表组件按当前主题初始化。
- 组件库「明/暗」Tab 决定添加组件时写入的默认 `theme` 与默认样式；编辑器自身界面（工具栏/面板）使用管理端浅色风格，画布内组件使用大屏主题。

### 2.4 管理端界面（编辑器/列表页）

使用 Element Plus 默认浅色风格，主色统一为 `#2F7FF7`；选中态/焦点态沿用主色。

**Element Plus 与原型自研组件的边界【已确认，v0.3 定稿】**：
- **用 Element Plus**：弹窗（ElDialog）、消息提示（ElMessage）、表单控件（输入框/下拉/开关/单选/复选/滑杆/取色器/上传）、日期等交互控件——这类组件原型只做视觉占位，真实开发一律用 EP 并覆盖主色，**不自研**。
- **从原型 `styles.css` 迁移**：设计 tokens（CSS 变量）、布局与皮肤类（topbar 导航壳、card 卡片、tag 状态标签、table 表格皮肤、chip 筛选、page-head、编辑器 `.ed-*`/画布/设置面板系列）——这些是产品视觉 identity，封装为少量布局/展示型 Vue 组件（如 `AppTopbar`、`PageHead`、`StatusTag`）。
- **大屏运行时（预览/展示页）不引入 Element Plus 重组件**，保持运行时轻量。
- 图标统一 `lucide-vue-next`（与原型 `icons.js` 图标名一一对照）。

## 3. 字体规范

| 场景 | 字体栈 | 字号 |
|---|---|---|
| 界面正文 | "PingFang SC","Microsoft YaHei",sans-serif | 12 / 14 |
| 大屏标题 | 同上，加粗 | 28~36 |
| 组件标题条 | 同上，加粗 | 16~18 |
| 数值/指标 | "DIN Alternate","Bahnschrift","Roboto Mono",monospace 回退 | 20~48（按组件） |
| 正文文本组件 | 同界面正文 | 可配 12~32 |

字重：常规 400，强调 600，数值 700。

## 4. 圆角 / 间距 / 阴影

- 圆角：控件 4px，面板/卡片 8px，弹窗 8px。
- 间距基线 4px：组件内边距默认 12/16，面板区块间距 16。
- 阴影：大屏组件默认无阴影（科技风用描边/渐变）；管理端卡片 `0 2px 8px rgba(15,23,42,.08)`。

## 5. 组件视觉规范

### 5.1 底板框（所有数据组件通用外框）

- 结构：标题条（左：斜切装饰+标题文字；右：可选单位/时间）+ 内容区。
- 标题条高 40px；背景 `--ds-bg-panel`；顶部 1px 渐变描边（primary→accent）。
- 可整体关闭（样式设置「底板框」开关）。

### 5.2 图表通用

- 坐标轴线/刻度线：`--ds-border`；轴标签 `--ds-text-2` 12px。
- 图例：`--ds-text-2`，默认右上或顶部居中（可配）。
- tooltip：`--ds-bg-panel-2` 背景 + `--ds-border` 描边。
- 网格线：虚线 `rgba(30,58,102,.6)`。

### 5.3 指标卡族

- 数值字体用数值字体栈；单位 `--ds-text-2` 12px；趋势上升 `--ds-success` ↓/↑ 徽章。
- 环形类：环宽 8~12px，轨道色 `--ds-border`，进度色取系列色板。

### 5.4 表格

- 表头：`--ds-bg-panel-2`，文字 `--ds-text-2`；行高 40px；斑马纹隔行 `rgba(22,41,78,.5)`。
- 告警列表：等级点标记（严重=danger / 重要=warning / 提醒=primary）。

### 5.5 控件

- 按钮常规态：primary 描边 + 半透明底；hover 加亮；按下缩放 .98。
- 下拉框：深色底 + 描边，弹出层同 tooltip 风格。
- 文本：无装饰，配置字体/字号/颜色/对齐。

## 6. 边框套系（装饰-边框）【已确认：3 套】

v1 三套，风格下拉切换：
1. 默认深蓝（深蓝科技）：四角切角 + 细描边 + 角部光点。
2. 工业蓝：粗描边 + 角标强化，偏重工业 HMI。
3. 科幻紫：紫描边 + 内发光角标。
> 边框为 SVG/CSS 绘制（不依赖位图），颜色随主题变量。原「橙金 / 青绿」两套已收敛移除。

## 7. 编辑器界面布局尺寸（以高保真原型实测为准【v0.3 回写】）

| 区域 | 尺寸 |
|---|---|
| 顶部工具栏 | 高 48px |
| 左侧面板（页面层级/组件库） | 宽 288px，可收起 |
| 右侧配置面板 | 宽 324px，可收起 |
| 画布 | 默认 1920×1080，背景点阵网格（编辑器内，可由「网格开关」切换显示） |
| 选中框 | 2px 主色描边 + 手柄 + 比例锁小锁（含名称角标） |

### 7.1 AI 智能设计助手

- 入口：编辑器右下角圆形悬浮按钮，使用 Lucide `WandSparkles` 图标；只在编辑器显示，预览页和展示页不出现。
- 面板：从右侧浮出，建议宽 440px、最大高度 `min(760px, calc(100vh - 72px))`；不覆盖顶部保存按钮。窄屏时宽度为视口减 24px。
- 面板只有一条任务流，不设置“使用帮助/知识库”Tab。顺序固定为：作用范围 → 上下文摘要 → 指令/参考图 → 生成 → 方案摘要与差异 → 预览/应用。
- 作用范围使用分段选择：选中组件 / 当前页面 / 整张大屏。整屏能力未开放时禁用并显示“性能验证后开放”。
- 上下文摘要用紧凑信息条显示目标数、锁定数、隐藏数和组件类型；锁定/隐藏跳过规则就近说明。
- 指令使用多行输入框；参考图区域支持拖拽和点击上传，显示缩略图、格式、大小和删除按钮。首次上传前展示“图片将发送至管理员配置的 DeepSeek 服务”提示。
- 主按钮文案为“生成修改方案”；请求中显示取消按钮与阶段文案，不使用无限等待的纯旋转图标。

### 7.2 方案、预览与异常状态

- 方案顶部显示摘要、修改对象数、字段数和主要颜色色块；批量方案按组件折叠，展开后显示“字段：旧值 → 新值”。
- 跳过项使用中性信息样式；近似还原使用 `--warn`；不支持项使用 `--err`，并显示原因与可选动作。
- “预览”进入画布临时态：画布顶部显示固定提示条“正在预览 AI 方案”，含“应用”“取消”按钮；预览不改变未保存状态标签。
- “应用”后提示“已应用，可撤销”，大屏状态变为未保存；一次 Ctrl+Z 恢复整份方案。
- 方案过期时差异区域整体降低透明度，显示“画布已变化，请重新生成”，禁用应用按钮。
- 模型未配置、视觉模型不可用、超时、限流、空响应、部分字段非法、全部非法均使用独立可重试状态；禁止仅显示通用“失败”。

### 7.3 我的组件与锁定样式

- 左侧组件库在四分类下增加来源分段：“内置组件 / 我的组件”。“我的组件”只显示图表和装饰，卡片展示预览图、名称、类型和更多菜单。
- 更多菜单：重命名、复制、删除；删除必须二次确认并说明“不会影响已经添加到大屏的组件”。
- 临时 AI 组件选中后，在配置面板顶部显示“AI 生成”标签和“保存为个人组件”按钮。
- `styleMode='locked'` 时隐藏样式表单，显示锁定说明与“根据新描述重新生成”；数据绑定和允许的交互事件保持可用。
- 动态组件快照或渲染器不可用时，画布和运行时统一显示“组件配置不可用”占位，不显示空白区域。

### 7.4 管理后台 AI 设置

- AI 设置只保留 DeepSeek 模型卡：BaseURL、API Key、文本模型、视觉模型、启用图片理解开关、分别测试文本/图片能力、保存。
- 默认值以占位提示展示：`https://api.deepseek.com`、`deepseek-v4-flash`、`deepseek-v4-flash-vision-exp`；API Key 只显示掩码，不提供读取明文动作。
- 文本和视觉测试结果分别显示成功/失败，视觉模型未配置时不影响文本能力。
- 不再显示知识库页签、文档列表、Embedding 模型或 BM25 说明。

## 9. 适配方式实现

- 画面居中：`scale = min(vw/1920, vh/1080)`，居中留黑边。
- 宽度铺满：`scale = vw/1920`，垂直居中裁切。
- 高度铺满：`scale = vh/1080`，水平居中裁切。
- 全屏拉伸：`scaleX/scaleY` 分别拉伸，不保比例。
- 实现：外层容器 `transform: scale()`，`transform-origin` 按模式设定；监听 resize 重算。
