# 大屏配置系统 设计规范（design.md）

> 版本：v0.3（交付开发版）。色值为初始值，整体视觉以「深色科技风」为默认、同时支持浅色主题；最终色值待用户审核微调。
> v0.3 变更：① §6 边框套系命名与冻结原型统一（青绿/橙金）；② §7 编辑器布局尺寸以高保真原型实测为准回写（48px 工具栏、288/324px 面板）。
> 实现方式：SCSS + CSS 变量（主题）+ ECharts 主题包。组件默认样式随明/暗主题各一套。

---

## 1. 主题机制

- 两套主题：`dark`（默认）/ `light`，通过根节点 `data-theme="dark|light"` 切换 CSS 变量。
- ECharts 注册两个主题包（`ds-dark` / `ds-light`），图表组件按当前主题初始化。
- 组件库「明/暗」Tab 决定添加组件时写入的默认 `theme` 与默认样式；编辑器自身界面（工具栏/面板）使用管理端浅色风格，画布内组件使用大屏主题。

### 2.4 管理端界面（编辑器/列表页）

使用 Element Plus 默认浅色风格，主色统一为 `#2F7FF7`；选中态/焦点态沿用主色。

**Element Plus 与原型自研组件的边界【已确认，v0.3 定稿】**：
- **用 Element Plus**：弹窗（ElDialog）、消息提示（ElMessage）、表单控件（输入框/下拉/开关/单选/复选/滑杆/取色器/上传）、日期等交互控件——这类组件原型只做视觉占位，真实开发一律用 EP 并覆盖主色，**不自研**。
- **从原型 `styles.css` 迁移**：设计 tokens（CSS 变量）、布局与皮肤类（topbar 导航壳、card 卡片、tag 状态标签、table 表格皮肤、chip 筛选、page-head、编辑器 `.ed-*`/画布/设置面板系列）——这些是产品视觉 identity，封装为少量布局/展示型 Vue 组件（如 `AppTopbar`、`PageHead`、`StatusTag`）。
- **大屏运行时（预览/展示页）不引入 Element Plus 重组件**，保持运行时轻量。
- 图标统一 `lucide-vue-next`（与原型 `icons.js` 图标名一一对照）。

## 3. 字体规范

| 场景 | 字体栈 | 字号 |
|---|---|---|
| 界面正文 | "PingFang SC","Microsoft YaHei",sans-serif | 12 / 14 |
| 大屏标题 | 同上，加粗 | 28~36 |
| 组件标题条 | 同上，加粗 | 16~18 |
| 数值/指标 | "DIN Alternate","Bahnschrift","Roboto Mono",monospace 回退 | 20~48（按组件） |
| 正文文本组件 | 同界面正文 | 可配 12~32 |

字重：常规 400，强调 600，数值 700。

## 4. 圆角 / 间距 / 阴影

- 圆角：控件 4px，面板/卡片 8px，弹窗 8px。
- 间距基线 4px：组件内边距默认 12/16，面板区块间距 16。
- 阴影：大屏组件默认无阴影（科技风用描边/渐变）；管理端卡片 `0 2px 8px rgba(15,23,42,.08)`。

## 5. 组件视觉规范

### 5.1 底板框（所有数据组件通用外框）

- 结构：标题条（左：斜切装饰+标题文字；右：可选单位/时间）+ 内容区。
- 标题条高 40px；背景 `--ds-bg-panel`；顶部 1px 渐变描边（primary→accent）。
- 可整体关闭（样式设置「底板框」开关）。

### 5.2 图表通用

- 坐标轴线/刻度线：`--ds-border`；轴标签 `--ds-text-2` 12px。
- 图例：`--ds-text-2`，默认右上或顶部居中（可配）。
- tooltip：`--ds-bg-panel-2` 背景 + `--ds-border` 描边。
- 网格线：虚线 `rgba(30,58,102,.6)`。

### 5.3 指标卡族

- 数值字体用数值字体栈；单位 `--ds-text-2` 12px；趋势上升 `--ds-success` ↓/↑ 徽章。
- 环形类：环宽 8~12px，轨道色 `--ds-border`，进度色取系列色板。

### 5.4 表格

- 表头：`--ds-bg-panel-2`，文字 `--ds-text-2`；行高 40px；斑马纹隔行 `rgba(22,41,78,.5)`。
- 告警列表：等级点标记（严重=danger / 重要=warning / 提醒=primary）。

### 5.5 控件

- 按钮常规态：primary 描边 + 半透明底；hover 加亮；按下缩放 .98。
- 下拉框：深色底 + 描边，弹出层同 tooltip 风格。
- 文本：无装饰，配置字体/字号/颜色/对齐。

## 6. 边框套系（装饰-边框）【已确认：3 套】

v1 三套，风格下拉切换：
1. 默认深蓝（深蓝科技）：四角切角 + 细描边 + 角部光点。
2. 工业蓝：粗描边 + 角标强化，偏重工业 HMI。
3. 科幻紫：紫描边 + 内发光角标。
> 边框为 SVG/CSS 绘制（不依赖位图），颜色随主题变量。原「橙金 / 青绿」两套已收敛移除。

## 9. 适配方式实现

- 画面居中：`scale = min(vw/1920, vh/1080)`，居中留黑边。
- 宽度铺满：`scale = vw/1920`，垂直居中裁切。
- 高度铺满：`scale = vh/1080`，水平居中裁切。
- 全屏拉伸：`scaleX/scaleY` 分别拉伸，不保比例。
- 实现：外层容器 `transform: scale()`，`transform-origin` 按模式设定；监听 resize 重算。
