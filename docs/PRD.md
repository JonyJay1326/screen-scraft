## 1. 产品概述

### 1.1 背景与目标

建设一套**独立的大屏（数据可视化看板）配置系统**。运营/业务人员通过拖拽、配置即可产出可投放展示的数据大屏，无需编写代码；技术人员通过「API 配置页」以写 SQL 或登记外部接口的方式为组件提供数据。

### 1.2 系统形态【已确认】

- 全新独立系统：前端编辑器 + 后端服务 + 数据库，不依附于现有系统。
- 支持**多项目**管理，每个项目下管理各自的大屏。
- **无发布流程**：保存即生效；「使用中」徽章 = 投放标记（手动标记，见 4.2）。

### 1.3 技术栈【已确认】

| 层 | 选型 |
|---|---|
| 前端框架 | Vue3 + TypeScript + Vite |
| 状态管理 | Pinia |
| HTTP 请求 | Axios（先按需求统一封装：拦截器/鉴权注入/错误处理，再供各模块使用）【已确认】 |
| UI 组件库 | Element Plus |
| 图表 | ECharts 5.x【已确认】 |
| 拖拽缩放 | vue-draggable-resizable-gorkys |
| 可编辑表格 | vxe-table（静态数据表格：动态行列 / 右键菜单 / 单元格编辑）【已确认】 |
| 代码编辑器 | CodeMirror 6（API 配置页 SQL 编写）【已确认】 |
| 样式/主题 | SCSS + CSS 变量（明暗双主题） |
| 后端 | NestJS（TypeScript） |
| 数据库 | MongoDB |

### 1.4 目标用户【已确认】

| 角色 | 主要操作 |
|---|---|
| 业务/运营人员 | 拖拽搭建大屏、配置静态数据、使用模板、标记投放 |
| 技术人员 | API 配置（SQL 生成 / 外部登记）、API 类数据源绑定、高级样式配置 |

### 1.5 v1 范围总览

**做**：多项目；大屏列表；模板库（公共/个人）；编辑器（图表/装饰/媒体/控件四大类组件）；数据绑定（静态数据 + API 接入）；交互事件（跳页面/跳超链接/显示隐藏/调 API/下拉框联动）；API 配置页（SQL 生成 + 外部登记，含占位符参数与试运行）；AI 智能设计助手（自然语言改样式、参考图风格迁移、安全自定义图表/边框、个人组件预设）；明暗双主题；撤销/重做；投放标记；极简用户管理（管理员）【已确认】。

**不做（预留扩展位）**：应用组件、页面链接（导航轮播类组件）、GIS 地图背景、字段映射（API 返回需直接符合组件数据协议）；AI 修改数据绑定/API 配置/交互事件/布局；AI 自动删除组件；执行 AI 生成的 Vue、JavaScript、CSS、SVG、ECharts 函数；截图像素级还原；组件市场与跨用户共享；知识库问答入口。

### 1.6 品牌【已确认】

- 英文系统名：**ScreenCraft**；中文副名：ScreenCraft 大屏配置系统。
- 登录页采用浅色等距插画风格（最终视觉后续由 UI 统一出稿，现有原型仅参考），见 design.md §8、`designs/login_mockup.html`。

## 2. 名词解释

| 名词 | 含义 |
|---|---|
| 项目 | 顶层组织单元，一个项目下有多块大屏 |
| 大屏 | 一个可投放的可视化作品，包含 1~N 个页面 |
| 页面 | 大屏内的一屏内容，页面间可跳转；支持父子层级（均为普通页面，层级仅组织展示）【已确认】 |
| 组件 | 画布上的一个可视化单元（图表/指标卡/表格/图片/视频/控件/装饰） |
| 组件模板（变体） | 组件库中一条可添加的组件定义，含预览图、默认尺寸、默认配置；**变体即独立组件**，添加后不可互切【已确认】 |
| 临时自定义组件 | AI 生成并加入当前大屏的安全图表或参数化边框；未保存为个人组件时不出现在组件库 |
| 个人组件预设 | 用户保存的可复用组件定义，仅本人可见；添加到画布时写入独立实例快照 |
| 组件定义快照 | 保存在 ComponentDoc 内的自包含安全定义；个人预设更新或删除后，旧大屏仍按快照渲染 |
| AI 修改方案 | AI 返回的结构化、可预览样式差异；应用前必须经后端和前端校验，不自动保存大屏 |
| 大屏模板 | 由大屏/页面另存得到的可复用作品，分公共/个人 |
| API 配置 | 全局数据接口定义，分「SQL 生成」「外部登记」与种子生成的「Mock 数据」三类 |
| 占位符参数 | API 配置中声明的参数，运行时由前端（如下拉框选中值）同名传入 |
| 交互事件 | 组件上「触发条件 → 实现动作 → 目标对象」的联动规则 |
| 投放（使用中） | 大屏被标记为正在展示设备上使用，列表页显示「使用中」徽章 |
| 适配方式 | 大屏在不同分辨率屏幕上的缩放策略 |

## 4. 功能明细

### 4.1 项目列表页【已确认】

默认设计：
- 展示项目卡片/列表：项目名称、大屏数量、更新时间。
- 操作：新建项目、重命名、删除（二次确认，需处理其下大屏）、进入项目。

### 4.2 大屏列表页

参考 `designs/01_大屏列表页.png`。

**顶部区域**
- 「新建空白模板」按钮：创建一块新大屏（默认 1920×1080、1 个页面、默认深色背景），并直接进入编辑器。
- Tab：我的大屏 / 模板（模板区见 4.3）。
- 分类筛选：全部 / 通用 / 工业 / 政务 / 医疗 / 交通 / 能源（与模板共用同一套分类）【已确认，v0.3 与原型统一】。

**大屏卡片**
- 展示：缩略图（保存时自动生成）、名称、分类标签。
- 「使用中」徽章【已确认】：表示该大屏处于投放中；通过卡片 ⋮ 菜单「标记为投放中 / 取消投放」手动切换。
- 操作：
  - 点击卡片 / hover「编辑」按钮 → 进入编辑器。
  - ⋮ 菜单：复制、删除（二次确认）、标记为投放中 / 取消投放。

### 4.3 模板库

- Tab 内切换：公共模板 / 个人模板；分类筛选同 4.2。
- 个人模板来源：编辑器「保存为模板」（弹窗填写名称 + 分类）。
- 模板卡片与操作【已确认】：缩略图 / 名称 / 分类；公共模板 → 以此模板新建大屏、预览；个人模板 → 额外支持删除。公共模板由管理员从个人模板提升而来。

### 4.4 编辑器

参考 `designs/02_编辑器整体.png`。整体布局：顶部工具栏；左侧面板（页面层级树 / 组件库，二选一或并列展开）；中部画布；右侧配置面板；画布内浮动元素（选中工具条、删除按钮）。

> 参考系统右上角「参数设置」按钮**不需要**【已确认】。

#### 4.4.2 页面层级（左侧树）

参考 `designs/02_编辑器整体.png` 左侧。
- 树形展示大屏全部页面，支持父子层级【已确认】：**父子均为可编辑、可跳转的普通大屏页面**，层级仅用于组织展示。
- 点击节点 → 画布切换到该页面。
- 树顶「+」添加页面；每个节点 ⋮ 菜单：重命名 / 删除（二次确认）/ 添加子页面。
- 该树同时作为「交互事件-跳页面」的目标选择来源。

#### 4.4.3 组件库（左侧面板）

参考 `designs/05~08`。
- 四个分类：图表 / 装饰 / 媒体 / 控件【已确认】。
- 每个分类顶部有**明/暗主题切换 Tab**【已确认】：切换后组件预览图与添加后的默认样式随主题变化；新系统需为每个组件模板提供明、暗两套默认样式。
- 组件卡片：预览图 + 名称；**点击添加到画布中央**【已确认】，再拖动定位。
- 组件库增加“我的组件”区域：登录后加载本人保存的图表和装饰预设；个人组件与内置组件使用同一添加交互，但实例必须复制安全定义快照，不实时追随预设更新。
- 组件清单见第 5 章。

#### 4.4.4 画布与组件操作

- 画布固定 1920×1080【已确认】。
- 组件基于 vue-draggable-resizable-gorkys：拖动移动、八向手柄缩放。
- 选中态：蓝色边框 + 八向手柄 + **比例锁小锁**（锁定后等比缩放）；普通组件显示名称角标，边框组件不显示名称角标【已确认】。
- 多选：Shift + 点击。
- 选中浮动工具条（参考 `designs/09_选中操作工具条.png`）：
  - 图层 ▾：置顶 / 置底 / 上一层 / 下一层
  - 显示 / 隐藏 / 锁定 / 解锁 / 组合 / 打散（组合/打散仅多选时可用）
  - 删除：选中框右侧独立垃圾桶按钮
- 操作语义【已确认】：
  - 锁定：可选中、可查看配置，但不可移动/缩放；
  - 隐藏：编辑器内半透明显示，大屏端（预览/投放）不渲染；
  - 组合：整体当作一个组件（移动/缩放/复制/删除），打散恢复独立；**双击组合进入「组内模式」**，可单独选中并配置组内组件，点击组外或 Esc 退出【已确认】。
- 快捷键（参考 `designs/03_快捷键弹框.png`，【已确认】含新增项）：

| 操作 | 快捷键 | 来源 |
|---|---|---|
| 移动画布 | 空格 + 左键 | 参考系统 |
| 删除组件 | Ctrl + BackSpace | 参考系统 |
| 多选 | Shift + 点击 | 参考系统 |
| 组件复制 | Ctrl + C | 参考系统 |
| 组件粘贴 | Ctrl + V | 参考系统 |
| 撤销 | Ctrl + Z | 新增 |
| 重做 | Ctrl + Shift + Z | 新增 |
| 保存 | Ctrl + S | 新增（v0.3 补齐，与工具栏保存等效） |
| 微调移动 | 方向键（Shift+方向键 10px） | 新增 |

- 画布缩放范围 20%~400%【已确认】。
- Ctrl+C/V 支持跨页面粘贴（同一大屏内），不跨大屏【已确认】。
- 浏览器关闭/刷新时若有未保存修改，弹原生确认提示【已确认】。
- 画布右下角不做小喇叭【已确认】：该位置为 **AI 智能设计助手悬浮入口**，仅编辑器显示；预览页和展示页均不显示 AI 入口。

#### 4.4.5 右侧配置面板

未选中组件时显示**页面（背景）设置**；选中组件时显示**组件设置**（数据绑定 / 样式设置 / 交互事件 三个 Tab，不同组件类型 Tab 组合不同）。

**A. 背景设置**（参考 `designs/02` 右侧、`designs/04_背景填充方式.png`）
- 背景类型单选：常规背景 / 应用组件（禁用，预留）/ 页面链接（禁用，预留）/ GIS地图（禁用，预留）。
- 背景颜色：取色器。
- 透明度：滑杆 + 百分比输入（0~100）。
- 图片：上传区。
- 填充方式：填充(cover) / 适应(contain) / 拉伸(100% 100%) / 平铺(repeat) / 居中(center)。

**B. 组件设置通用结构**
- 面板顶部：组件名称（可编辑）+ 显示(眼睛)/隐藏 + 锁定/解锁 快捷图标。
- Tab 组合：
  - 数据类组件（图表/指标卡/表格/天气）：数据绑定 / 样式设置 / 交互事件（下拉框的交互事件为联动专用，见 4.4.6）。
  - 图片/视频/边框：数据绑定（资源来源）/ 样式设置。
  - 按钮/文本：样式设置 / 交互事件。
  - 下拉框：数据绑定（选项）/ 样式设置 / 交互事件（联动）。
  - 锁定样式的 AI 自定义图表：保留数据绑定和允许的交互事件，不显示可编辑样式表单；用户可通过“根据新描述重新生成”创建新方案。

**C. 数据绑定 Tab**
- 数据来源下拉：静态数据 / API 接入。
- 静态数据【已确认】：
  - 按组件数据协议（第 5 章）**动态生成表格**，可直接编辑单元格；
  - 支持动态加行加列；右击行/列弹出菜单：插入行（上/下）、删除行、插入列（左/右）、删除列（参考 `designs/11_静态表格右键菜单.png`；菜单项【已确认】：插入行上/下、删除行、插入列左/右、删除列）。
- API 接入：
  - 选择全局 API（来自 API 配置页）；
  - 仅展示 `dataProtocol` 与当前组件一致的 API；历史配置未声明协议或已绑定 API 不兼容时明确提示并要求重新选择；
  - 自动刷新：轮询秒数输入（仅 API 类数据源显示；静态数据不显示）【已确认】；
  - API 含占位符参数时，参数值来源：同名自动注入（如下拉框联动）【已确认】；v1 不做手动字段映射。

**D. 样式设置 Tab**
- 通用项（所有组件）：底板框开关/样式（组件整体外框：标题条+背景板）【已确认】、标题文字、内边距等。
- 图表类：按图表类型的配置项清单【已确认，每类 5 变体】，默认包含：系列颜色列表、坐标轴显示/颜色、图例显示/位置、数值标签显示、线条/柱宽等（参考 `designs/12_图表样式设置.png`）。
- 图片：圆角、边框等（参考 `designs/13_图片组件设置.png`）。
- 按钮：按钮类型（常规/图片/热区）、文字、颜色、字号等（参考 `designs/14_按钮样式设置.png`）。
- 文本：字体 / 字号 / 颜色 / 对齐方式【已确认】；文本内容在画布上双击编辑。
- 下拉框：字体/颜色等基础样式 + **默认选中项**（可选；配合参数默认值用于联动组件首次取数，见 4.4.6）【已确认】。

#### 4.4.6 交互事件系统

参考 `designs/15~21、24`。一个组件可配置多条事件，每条事件 = 触发条件 + 实现动作 + 目标对象。

**触发条件**（按钮等通用组件）：鼠标点击 / 鼠标双击 / 鼠标进入 / 鼠标离开。
**下拉框专用**：触发条件与实现动作固定（选中即触发、动作=调 API 接口），触发范围=下拉选项（所有选项选中时均触发）【已确认】。

**实现动作**：

| 动作 | 配置项 | 说明 |
|---|---|---|
| 跳转页面 | 目标对象=页面（从页面层级树选择） | 预览端切换到目标页面 |
| 跳转超链接 | 打开方式（新窗口/当前窗口）+ 链接地址 | |
| 显示/隐藏 | 目标对象=组件列表（多选）+ 状态（显示/隐藏/切换） | 控制其他组件可见性 |
| 调 API 接口 | 目标对象=数据组件列表（多选） | 触发目标组件重新请求其绑定的 API |

**下拉框联动**【已确认】：下拉框选中值作为参数，**按同名约定**自动注入目标组件所绑定 API 的同名占位符参数，目标组件重新取数渲染。即：下拉框选项 value 的取值需与目标 API 参数值域匹配（文档与界面提示中需说明该约定）。页面加载（首次取数）时，目标组件使用 API 配置中声明的参数 `defaultValue` 请求；用户切换下拉后改用选中值注入【已确认】。

## 6. API 配置页【已确认】

> 新功能：把数据接口配置产品化。配置后后端自动生成可访问的 API，供组件数据绑定选择。

**列表页**：API 名称 / 类型（SQL 生成 / 外部登记 / Mock 数据）/ 路径 / 更新时间 / 操作（编辑 / 删除 / 试运行）。

**配置表单**：
- 基本信息：名称、分类标签（可选）、数据协议（必填，用于标识可绑定的图表/组件）。
- 类型一 **SQL 生成**：选择数据源连接（v1 内置一个业务库连接，只读账号；**数据源类型可配置，v1 默认 MySQL，后端预留多数据库驱动抽象**【已确认】）+ 编写 SQL + 声明占位符参数（参数名/类型/默认值）。后端将 SQL 包装为只读查询接口（强制只读、防注入：参数化绑定）。
- 类型二 **外部登记**：登记外部 API 的地址 / 请求方法 / 请求头 / 鉴权方式 / 参数声明，后端做透传代理（解决跨域与鉴权收口）。
- 类型三 **Mock 数据**：仅由演示种子生成，数据存入 MongoDB `mock_datasets`；管理端不提供手工新建入口，可像普通 API 一样绑定、试运行和参与下拉联动。
- **占位符参数**：声明后，SQL/请求中以 `:paramName` 引用；前端运行时由同名值注入（如下拉框联动）。
- **试运行**：填入参数示例值 → 执行 → 展示返回结果（JSON 表格预览），用于验证协议是否符合组件要求。
- **删除保护**【已确认】：API 被组件引用时禁止删除，提示引用数量。

## 7. AI 智能设计助手【已确认，v0.4】

### 7.1 入口与模型

- 入口仅位于编辑器右下角；预览页和展示页不显示 AI。
- 后端通过 OpenAI 兼容的 DeepSeek API 调用模型，默认 BaseURL `https://api.deepseek.com`；文本模型默认 `deepseek-v4-flash`，参考图模型默认 `deepseek-v4-flash-vision-exp`，模型名均由管理员配置，不写入大屏数据。
- 管理后台只保留模型配置、连接测试和能力状态；不再展示知识库管理。旧 `/ai/chat`、`/ai/kb-docs*` 停止新调用，既有知识库数据不自动删除。
- 文本模型不可用时全部 AI 能力禁用；视觉模型不可用时保留文本改样式，参考图入口显示明确原因。

### 7.2 作用范围与方案

- M9.1 开放“选中组件”，M9.2 开放“当前页面”；“整张大屏”在 M9.2 完成 200 组件性能验证后再开放。
- 选中范围无组件时禁止提交；锁定组件始终跳过；隐藏组件默认跳过，只有用户明确要求时纳入。
- 组外选中组合时按整组处理；处于组内模式时只处理实际选中的子组件。
- AI 只返回结构化修改方案。方案至少显示修改对象、字段数量、主要颜色变化、跳过项、不支持项和风险提示。
- 方案先预览后应用。预览使用独立 draft，不写正式 screenStore 和历史栈；应用通过一个原子 store 动作完成，只产生一条撤销记录，并保持大屏“未保存”。
- 编辑器维护本地 `editorRevision`。生成方案后画布发生任何正式变更，方案即过期，禁止直接应用；重新生成或重新校验后才能继续。

### 7.3 样式安全边界

- 修改内置或可编辑个人组件时，只能写入其共享 `styleSchema` 声明的字段；页面操作只能写入正式契约允许的背景字段。
- AI 不得修改组件位置、尺寸、层级、锁定、隐藏、分组、数据绑定、API 配置、事件、权限和所有者，也不得自动删除组件。
- 所有 AI 输出均视为不可信输入：后端依据共享字段目录校验，前端应用前再次校验；非法字段丢弃并显示原因，全部非法时禁止应用。
- 禁止函数 formatter、脚本、HTML、动态 CSS、完整 SVG/XML、外部资源 URL、自定义 `renderItem` 和危险对象键；纯文本固定占位符 formatter 与受复杂度限制的 `path://` 可用。
- 效果无法表达时依次采用：精确映射 → 安全近似 → 建议生成临时自定义组件 → 经用户确认生成锁定样式图表 → 明确不支持。不得静默忽略。

### 7.4 参考图

- 支持 PNG、JPEG、WebP，单张不超过 10MB；校验扩展名、MIME 和真实文件头。
- 图片仅通过后端以内联 Base64 发送给管理员配置的 DeepSeek 视觉模型，前端不接触密钥，不生成公网图片 URL。
- 上传前提示图片会发送至第三方模型服务；临时参考图按过期策略清理，保存个人组件时只保留生成结果所需资产。
- 图片中的文字指令是不可信内容，不能覆盖系统规则、修改数据或触发外部操作。

### 7.5 自定义组件与个人组件

- 首期支持安全自定义图表和参数化边框。图表继续声明现有数据协议并使用中文模拟数据，不增加字段映射层。
- 可编辑图表使用 `echarts-safe-v1` 的批准字段；现有字段无法表达但声明式配置可以安全表达时，可生成 `styleMode='locked'` 的锁定样式图表，数据绑定保持独立可编辑。
- 新生成图表使用向后兼容的 SafeChartSpec v2，七个图表族的纯 JSON 视觉与布局字段统一投影到固定 renderer 节点；布局、标签、渐变、阴影、强调态、动画及特殊图表结构不再逐字段补白名单。安全归一化不降级，视觉信息真实丢失才标记“近似还原”，危险或可执行字段硬拒绝。
- 生成结果显示“精确还原 / 近似还原”；无法安全表达的视觉效果逐项显示“不支持”和原因。
- 参数化边框使用 `border-parametric-v1` 和受控 SVG DOM/CSS 变量；透明图片九宫格边框按已确认的 M9.6 单独实现。
- 用户可保存、重命名、复制、更新和删除个人组件。保存后仅创建者可见；管理员提升公共组件仅保留接口和权限，首期不开放 UI。
- 更新个人预设时递增 `specVersion` 并更新当前定义，首期不提供历史版本回滚。已有大屏实例不跟随更新；删除预设只删除组件库入口，旧实例继续使用 `definitionSnapshot`。
- 快照无效或渲染器版本不支持时显示“组件配置不可用”，不得白屏。

### 7.6 整屏截图模型能力测试【已确认】

- 编辑器可复用临时参考图执行一次整屏结构识别测试；通常拆分 8～20 个主要组件，复杂页面允许超过 20 个并提示人工检查，硬上限为 32 个。
- 测试只识别画布尺寸、忽略区域、组件类别、可见文字、位置尺寸和置信度，不生成可执行配置，不新增页面、不修改画布、不写大屏数据库。
- 组件类别限定为 `text / kpi / kpiList / line / bar / pie / gauge / table / border / unsupported`；卡片背景合并到内容组件，系统导航等区域单独列入忽略区域。
- 页面级照片、园区全景、插画、视频或三维/GIS 场景通过可选 `canvas.backgroundLayer` 描述类型、可见范围、语义、置信度和交互不确定性，不作为普通组件，也不包含图片 URL 或数据。类型限定为 `image / interactiveScene / video / unknown`。
- `ignoredRegions` 只记录与当前大屏无关的应用导航等系统界面；大屏自身的告警条、主标题、日期、天气、筛选和全屏控件必须保留为内容。
- 页面同时展示模型原始 JSON 和共享契约问题；即使结果不合法也保留原文供人工评估，禁止把该诊断结果直接接入保存或应用链路。
- 解析结果按组件坐标确定性重排，但原始 JSON 不修改；校验需报告按列输出、大面积重叠、虚构标题和图表系列数误用。
- 基础字段可解析时生成本地结构草稿：在参考图上叠加组件边界，允许修改名称、类型、原始像素坐标和尺寸，并可排除误识别组件。
- 结构草稿确认前实时检查空列表、越界和大面积重叠；`unsupported` 可保留为待人工匹配项。确认状态仅存在于当前 AI 面板，不进入画布、历史栈或数据库。
- 不得为了满足数量目标强行合并不同编辑单元；草稿超过 20 个组件时提示检查可合并项或误识别项，但不阻止确认。
- 同一总标题和外层卡片内纵向连续的 KPI、进度条及对比指标作为一个 `kpiList`，边界覆盖完整复合分析区；不得拆成标题、进度条和若干窄行。
- 单一图表、仪表盘或表格面板的标题栏、页签、图例和主体必须合并为一个组件；背景层附属的播放、视角、显隐和视频工具栏归入背景层说明，不单独拆分。
- KPI 与拥有独立绘图区、坐标轴或柱线主体的图表即使位于同一外层卡片，也必须拆成独立编辑单元；解析层会移除三维/视频背景下被重复识别的场景控制栏，但不猜测拆分图表坐标。
- 名称以“标题”结尾、与同名主体同列紧贴且主体标题为空的游离文本由解析层并入主体；页面主标题等无法明确归属的文本保持独立。
- `notes` 明确声明含仪表盘且可见文字包含稼动率及多项运行状态时，误标为 KPI 的结果由解析层纠正为 `gauge`；图表与汇总 KPI 互相吞并但无法可靠推断坐标时只报告问题，不自动切框。
- 同一外层卡片拆出的 KPI 与图表必须分别框选各自子区域，禁止复用相同父卡片边界或产生大面积重叠；坐标不可靠时由校验阻止确认并交给人工调整。
- 模型已提供同高或同宽图表子区域、且 KPI 父边界完整包含该图表时，解析层可沿图表边缘收缩 KPI 边界；没有明确子区域时禁止推测拆分比例。
- 图片继续使用既有真实文件头、10MB、单边 8192px、ownerId 和 TTL 规则；视觉模型、JSON Output、空响应重试、取消与用户级限流复用现有 AI 链路。

### 7.7 整屏结构草稿生成新页面【已确认】

- 已确认的结构草稿先转换为本地页面骨架预览，展示组件类型到内置模板的确定性映射、跳过项和坐标缩放说明；预览阶段不修改正式画布。
- 用户点击“添加为新页面”后在当前大屏末尾追加一个页面并自动切换，不覆盖现有页面、不自动保存数据库；整次追加只写入一条撤销历史。
- 新页面复用当前大屏的全局画布尺寸。参考图尺寸不同时按等比包含并居中投影全部组件，禁止拉伸单个组件或修改其他页面共用的画布尺寸。
- `text / kpi / kpiList / line / bar / pie / gauge / table / border` 映射到固定内置模板；优先使用模型返回并通过协议校验的视觉样式与 `mockData`，旧结果缺少模拟数据时允许从组件内可见的简单数值文字安全推导 KPI、名值图和表格数据，无法推导才回退模板演示数据。
- `unsupported` 组件不自动生成并逐项提示；`backgroundLayer` 只保留诊断警告，新页面仅应用识别到的纯色背景，不把临时参考图、三维场景、视频或定位标记写入页面。
- 新页面写入后仍处于未保存状态，由用户检查、编辑并手动保存。撤销删除本次新增页面，重做恢复页面并保证当前页面指向有效页面。

### 7.8 整屏视觉样式与模拟数据迁移【已确认】

- 整屏识别结果增加页面级视觉主题和组件局部样式差异，字段仅包含颜色、边框、圆角、间距、字号及受控图表形态；禁止返回 CSS、HTML、SVG、函数、URL 或原始 ECharts option。
- 页面级主题用于复用面板背景、边框、标题、正文、数值和强调色色板；组件仅输出与页面主题不同的局部覆盖，避免复杂截图造成响应过长。
- 可见业务数据按现有数据协议输出为可选 `mockData`：KPI、指标列表、坐标轴图、名值图、仪表盘和表格分别执行既有 shared 协议校验；无法可靠识别时省略并回退模板模拟数据。
- 页面骨架生成时只投影注册表已声明的安全样式字段；模型样式与数据不合法时降级到内置默认值并显示警告，不阻止其余合法组件生成。
- 截图中确实可见的常规功能图标可映射为受控 Lucide 图标名，并迁移图标前景色与背景色；找不到近似图标时省略，品牌 Logo、复杂设备图形不切图、不虚构。
- 图表周期切换、日期范围和“更多”等附属控件只复刻截图当前静态外观，不推断或生成业务交互；截图当前展开的 tooltip 可作为静态演示层迁移，未展开时禁止虚构。滚动状态和截图中不可见的完整图表数据不做虚构；图表曲线数据允许近似，并通过 `dataConfidence` 和 warnings 提醒人工复核。

## 9. 非功能需求

- 编辑器画布操作流畅（组件数 ≤ 100/页 时无明显卡顿）。
- 大屏 JSON 保存采用整屏覆盖式版本化存储，支持撤销/重做（编辑器内存栈，v1 不做历史版本回滚）。
- 安全：SQL 生成类 API 强制只读 + 参数化；外部登记 API 由后端代理，不向浏览器暴露鉴权信息。
- 主题：明/暗双主题通过 CSS 变量 + ECharts 主题包实现，组件默认样式随主题切换。
- 接口风格【已确认】：v1 后端接口只使用 GET / POST（**不使用 PUT / DELETE**），更新/删除走 POST 动作路径，详见 api.md。
- 轮询：自动刷新默认 30 秒、最小 5 秒（天气默认 300 秒）；请求完成后再计时并加入 ±10% 抖动，避免慢请求重叠和同一时刻集中刷新【已确认】。
- 多图表加载：当前页运行时请求最多 6 并发，相同 API + 参数的并发请求合并；组件渐进挂载，隐藏组件不取数。页面切换、组件隐藏/卸载、联动参数变化时取消旧请求，迟到响应不得覆盖新数据【已确认】。
- 运行时数据异常【已确认】：API 请求失败或返回不符合协议 → 组件显示「数据加载失败」占位（有轮询则下次轮询自动重试）；编辑器内静态数据不符合协议 → 黄色警告提示，不阻断保存。
- 并发编辑：v1 不做协同；保存携带 updatedAt 做旧版本检测并提示【已确认】。AI 方案的本地过期检测使用 `editorRevision`，与服务端保存冲突使用的 `updatedAt` 分离。
- AI 性能：当前页最多处理 50 个组件，整屏最多 200 个；限制返回操作数、嵌套深度、字符串和数组长度；关闭面板、组件卸载或重新提交时取消旧请求。
- AI 调用：首期提供服务端用户级限流与调用统计，不建设费用额度系统；模型超时、限流、空响应和格式错误均显式报错。DeepSeek JSON 输出为空时允许自动重试一次，仍失败则不改变画布。
